# Results collation (mean ± std)

After test-set evaluation, collate metrics into tables under `results/`.

Per-seed and aggregate result files live under `by_seed/` and `combined/`.
Prostate and bladder stay **separate**. Every ladder rung (box, point, fixed ratios, policies, BAP-MOS, baselines) is a `method` folder under `by_seed/`.

> **Note:** The `results/` directory contains aggregates generated by the released
> reproduction pipeline. Values reported in the manuscript correspond to the
> paper’s final experimental tables.

## Metric units

- **Prostate TRUS:** MSD and HD95 are reported in **millimeters**, using native physical spacing.
- **External PFUS1:** MSD and HD95 reported in the paper use **pixel-equivalent units** (not physical millimeters).

CSV column names (`msd_mm`, `hd95_mm`) are shared across corpora for schema consistency; for PFUS1 paper tables, interpret distance columns as pixel-equivalent units.

## Prostate multi-site rule (critical)

Training uses the **pooled** corpus. Inference is exported **per test site** (`simulation`, `case1`, `case2`) for clarity. Aggregate numbers are **not** an unweighted average of those three site means.

Pooling procedure:

1. Load `per_slice_metrics.csv` from each site.
2. Keep rows with `valid_boundary` (relevant slices).
3. Concatenate across sites and take the arithmetic mean per organ.

\[
\frac{\sum_s (\mathrm{site\_mean}_s \times n_s)}{\sum_s n_s}
\]

Mean±std across seeds 42/43/44 is then taken on those **already pooled** values.

## Layout

```text
results/prostate/pooled/
  by_seed/<method>/<run_name>.csv
  combined/
    prostate_pooled_mean_std.csv           # all organs, site=pooled
    prostate_pooled_ptv_mean_std.csv       # PTV only (primary prostate organ)

results/bladder/pfus1/
  by_seed/<method>/<run_name>.csv
  combined/
    bladder_pfus1_mean_std.csv
    bladder_pfus1_bladder_mean_std.csv     # Bladder only (primary organ)
```

`combined/` holds the aggregated reproduction results. Local audit/status files may be regenerated during development but are gitignored.

## Per-seed columns

`method, run_name, seed, site, organ, dice, msd_mm, hd95_mm, n_slices, source`

(See **Metric units** above for how to interpret the distance columns per corpus.)

## Mean±std columns (`combined/`)

`method, run_name, organ, site, n_seeds, seeds, dice_mean, dice_std, dice_mean_pm_std, …` (same for `msd_mm`, `hd95_mm`).

`run_name` separates experiments within one `method` (e.g. three `box_point` ratios, four `boxpoint_box_point` mixes). For `box` / `point`, `run_name` is `pooled` (seed suffix stripped). Prostate aggregates use **`site=pooled`** only.

IoU may appear in raw export CSVs but is **not** collated into `results/`.

## Inference folder vs collation `run_name` (prostate legacy)

| `method` | Inference folder (`inference_output/prostate/pooled/…`) | `run_name` in `by_seed/*.csv` |
|----------|-----------------------------------------------------------|-------------------------------|
| `box` | `box/box_pooled_seed42` (etc.) | `pooled_seed42` — **no** `box_` prefix |
| `point` | `point/point_pooled_seed42` | `pooled_seed42` |
| `box_point` | `box_point/box50_point50_seed42` | same as folder name |
| `boxpoint_box_point` | `boxpoint_box_point/ratio_1_1_1_balanced_seed42` | same as folder name |
| policies | `<policy>/ucb1_global_seed42` | same as folder name |

Three seeds per experiment: `*_seed42`, `*_seed43_rep2`, `*_seed44_rep3`. See `docs/SEEDS.md`.

## Automated populate

After test exports land under `inference_output/prostate/pooled/`:

```bash
# Legacy ladder + main path + baselines (batch ingest + rebuild combined/)
bash scripts/populate_results_prostate.sh

# Legacy ladder only
LADDER_ONLY=1 bash scripts/populate_results_prostate.sh

# Rebuild combined/ only (skip ingest)
BUILD_ONLY=1 bash scripts/populate_results_prostate.sh
```

Or via helper: `./scripts/bapmos.sh populate-prostate`

Full training/export workflow: `docs/RUNNING.md`. Published CSVs: `results/README.md`.

## CLI

```bash
export PYTHONPATH="$(pwd)/src${PYTHONPATH:+:$PYTHONPATH}"

# box: run_name is pooled_seed42 (not box_pooled_seed42)
python -m bapmos.results.collate_seeds ingest-run \
  --corpus prostate --method box --run-name pooled_seed42 \
  --run-dir inference_output/prostate/pooled/box/box_pooled_seed42

# box_point: run_name matches inference folder
python -m bapmos.results.collate_seeds ingest-run \
  --corpus prostate --method box_point --run-name box50_point50_seed42 \
  --run-dir inference_output/prostate/pooled/box_point/box50_point50_seed42

# Ingest seeds 42, 43, and 44 from inference_output/ before build
# (see docs/RUNNING.md / docs/SEEDS.md for the export step).
python -m bapmos.results.collate_seeds build --corpus prostate
# → combined/prostate_pooled_mean_std.csv
# → combined/prostate_pooled_ptv_mean_std.csv
```
